# Basic ERP System

A simple Employee Management System built with React, Node.js, Express, and MongoDB.

## Setup Instructions

### 1. Install Backend Dependencies
```bash
cd backend
npm install
```

### 2. Start MongoDB
Make sure MongoDB is running on your system (should auto-start if installed as service).

### 3. Start Backend Server
```bash
cd backend
npm run dev
```
Backend runs on: http://localhost:5000

### 4. Start Frontend
Open a new terminal:
```bash
cd frontend
npm run dev
```
Frontend runs on: http://localhost:5173

## Features
- View all employees
- Add new employee
- Edit employee details
- Delete employee
- Responsive design

## Tech Stack
- **Frontend**: React + Vite, React Router, Axios
- **Backend**: Node.js, Express
- **Database**: MongoDB
